## llama master clinet for LAN (or wan)

- llama.master client is located in client/ folder 
- llama.master client is standalone aio app that provides connection to llama.master server in a way that user can conect and chat with the AI LLM running llama.master server
- client doesn't control llama master server, it can just discover it and use it fo chatting
- it provides simple interface basically with discovery button that will discover llama.master on llama master network or allows to put IP address (or hostname) manually and connect it
- it shows llama.master status
- it can discover running llama master
- it shows what model is running on llama.master (if any)
- it provides comfortable and pleasant user experience for llama.master
- it is electron app
- it provides full-featured chat client with all possible features (text properly formatted, copy paste, tok/s metric, clear button, syntax highlight, thouht...
- it shows how occupied llama.master server is and estimated tok/ps and response time


## Ui
- client has dark and light theme
- answer can be put to clipboard
- client has icons to increase or dicrease font size
